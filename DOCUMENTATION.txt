================================================================================
1. PROJECT OVERVIEW
================================================================================

This system performs semantic segmentation for infrastructure defect detection
on bridge imagery captured via UAV. It targets four defect categories:

  Class 0 – Background      (non-defect pixels)
  Class 1 – Crack           (linear surface damage)
  Class 2 – Spall           (surface layer detachment)
  Class 3 – Delamination    (reserved; no annotations yet)
  Class 4 – Moisture        (water ingress / staining)

Seven segmentation model variants are implemented, each in its own folder
under models/, sharing training/data infrastructure from common/:

  - Single-Modal v1/v2   : one 3-channel image per sample, no explicit fusion.
  - Early Fusion v1/v2   : one 4-channel RGB+IR fused TIFF per sample,
                            projected to 3 channels via a learnable 1x1 conv
                            before a single backbone. v2 (the primary model)
                            adds an ASPP decoder and Focal+Dice loss.
  - CNN-ViT-Self         : one 4-channel RGB+IR fused TIFF per sample, fed
                            directly (no channel projection) into a
                            from-scratch CNN + self-attention hybrid backbone
                            — the only model here with no pretrained weights.
  - MobileNetV4          : one 4-channel RGB+IR fused TIFF per sample,
                            projected to 3 channels (same scheme as Early
                            Fusion) into a pretrained MobileNetV4-Conv-Medium
                            backbone. Backbone choice documented in
                            docs/MobileRankings_TIMM.docx.
  - Late Fusion v1/v2    : separate RGB and IRT (infrared thermal) images per
                            sample, fused at the decoder stage via learned
                            modality attention.

A ninth, separate model (models/yolov11_defect_detection/) performs
single-class object detection (bounding boxes) with YOLOv11, rather than
per-pixel segmentation.

v1 variants use a MobileViT-S backbone; v2 variants use MobileViTv2-100 —
both hybrid CNN-ViT architectures from the `timm` library. The system is
built on PyTorch. See README.md for the full model comparison table and
models/<name>/README.md for each model's specifics.


================================================================================
2. SYSTEM ARCHITECTURE
================================================================================

HIGH-LEVEL FLOW (Late Fusion — models/late_fusion_v1, models/late_fusion_v2)
------------------------------------------------------------------------------

  RGB Image [B, 3, H, W] ──→ RGB Backbone (MobileViT-S/v2) ──→ RGB Features
                                                                          \
                                                               Modality    → Fused → Decoder → Segmentation
                                                               Attention  /           Map
  IRT Image [B, 1, H, W] ──→ IRT Backbone (MobileViT-S/v2*) ──→ IRT Features
                                                                          /

  * IRT backbone first Conv2d adapted: 3-channel → 1-channel input
    (pretrained RGB filters are summed across channels to preserve energy)

DECODER STAGES
--------------
The decoder progressively upsamples the fused feature map by 2× at each of
5 stages until the original image resolution is restored (stride 32 total).

  - Stages 1 & 2: Modality attention applied (lowest resolution; cross-modal
    context is most valuable at coarse scales)
  - Stages 3–5: Single fused pathway (higher resolution, efficiency priority)

EARLY FUSION FLOW (models/early_fusion_v1, models/early_fusion_v2)
--------------------------------------------------------------------

  Fused RGBT [B, 4, H, W] ──→ 1x1 Conv (4ch→3ch) ──→ Backbone (MobileViT-S/v2)
                                                              │
                                        Decoder (bilinear head v1 / ASPP head v2)
                                                              │
                                          Segmentation Map [B, num_classes, H, W]

  v2's ASPP decoder (atrous spatial pyramid pooling) replaces the plain
  bilinear-upsample head to recover fine structural detail (crack edges,
  moisture boundaries) lost in deep backbone features.

SINGLE-MODAL FLOW (models/single_modal_v1, models/single_modal_v2)
----------------------------------------------------------------------

  Image [B, 3, H, W] ──→ MobileViT-S/v2 Backbone ──→ Features [B, C, H/32, W/32]
                                                              │
                                            5-Stage Decoder (2× upsample each)
                                                              │
                                          Segmentation Map [B, num_classes, H, W]

  NOTE: common/dataset.py's COCOSegmentationDataset always yields a 4-channel
  [RGB, IR] tensor (IR zero-filled if absent), but this model's backbone
  expects 3-channel input — see models/single_modal_v1/README.md and
  models/single_modal_v2/README.md for this known mismatch.


================================================================================
3. DATASET & ANNOTATIONS
================================================================================

SOURCE ANNOTATIONS
------------------
Raw annotations are stored in CVAT 1.1 XML format (ANNOTATED_DATA/*.xml).
The class CVATXMLToCOCOConverter (common/dataset_utils.py) converts these
into COCO-format JSON files at runtime if they are missing or empty.

  - Cracks   → rendered as thick polylines (line width = 10 px), because
               cracks are linear features, not filled regions.
  - Spalls   → rendered as filled polygons.
  - Moisture → rendered as filled polygons.
  - Delamination → reserved; no annotations currently present.

COCO JSON STRUCTURE
-------------------
After conversion, two JSON files are produced:
  dataset/instances_train.json   (80% of images)
  dataset/instances_val.json     (20% of images)

SPLIT RATIO
-----------
train_ratio: 0.8  →  80% train, 20% validation (no separate test set yet)

IMAGE DIRECTORIES
-----------------
  RGB_FITTED/   — RGB imagery (PNG, 000000.png … 000068.png)
  IRT_FITTED/   — IRT thermal imagery (JPG, matching stems)
  FUSED/        — Pre-fused single-modal images (for single-modal pipeline)

CLASS IMBALANCE NOTE
--------------------
Defect pixels are rare relative to background. Class-weighted loss is used
to compensate (see Section 6.1).


================================================================================
4. DATA LOADING & AUGMENTATION
================================================================================

4.1 COCOSegmentationDataset  (single-modal)
-------------------------------------------
File: common/dataset.py

  - Loads from COCO JSON annotation files.
  - Renders polygon/polyline masks per image on the fly.
  - Returns: dict { "image": Tensor[3,H,W], "mask": Tensor[H,W], "image_id" }
  - Normalization: ImageNet mean/std  (mean=[0.485,0.456,0.406],
                                        std =[0.229,0.224,0.225])

4.2 MultiModalDataset  (dual-modal)
------------------------------------
File: common/dataset.py

  - Loads paired RGB and IRT images matched by file stem.
  - Returns: dict { "rgb": Tensor[3,H,W], "irt": Tensor[1,H,W],
                    "mask": Tensor[H,W], "image_id" }
  - RGB Normalization: ImageNet mean/std.
  - IRT Normalization: min-max scaling to [0, 1].

4.3 Augmentation Pipeline  (albumentations)
--------------------------------------------
Geometric transforms (applied identically to image, IRT, and mask):
  - HorizontalFlip           p = 0.5
  - VerticalFlip             p = 0.5
  - RandomRotate90           p = 0.5
  - ShiftScaleRotate         shift=0.1, scale=0.1, rotate=±15°, p = 0.5

Photometric transforms (image only):
  - ColorJitter              (configurable)
  - GaussianBlur             kernel 3–5 px, p = 0.3
  - GaussNoise               variance 10–50, p = 0.3

Synchronization: albumentations' `additional_targets` mechanism ensures
geometric transforms are applied identically to all channels (RGB, IRT, mask),
preventing label misalignment.

5. MODELS
================================================================================

5.1 MobileViTSegmentationModel / MobileViTv2SegmentationModel  (single-modal)
-------------------------------------------------------------------------------
Files: models/single_modal_v1/model.py (v1), models/single_modal_v2/model.py (v2)

  Backbone:  MobileViT-S (v1) / MobileViTv2-100 (v2), from timm, pretrained on
             ImageNet. Fallback: mobilenetv3_small_100 (v1) / mobilevitv2_075 (v2)
             if the primary backbone is unavailable.
             Output: feature map [B, C, H/32, W/32]

  Head:      common.heads.MobileViTSegmentationHead
             5-stage decoder; each stage:
               Conv2d(in_ch → hidden_dim) → BN → ReLU → 2× bilinear upsample
             Final: Conv2d(hidden_dim → num_classes), no activation
                    (logits fed directly to CrossEntropyLoss)

  hidden_dim: 256 (configurable)

  Forward signature:
    model(image: Tensor[B,3,H,W]) → logits: Tensor[B,num_classes,H,W]

  KNOWN ISSUE: the shared common.dataset.COCOSegmentationDataset always
  returns a 4-channel [RGB, IR] tensor, but this model expects 3-channel
  input — see models/single_modal_v1/README.md.

5.2 EarlyFusionSegmentationModel / EarlyFusionSegmentationModelV2
--------------------------------------------------------------------
Files: models/early_fusion_v1/model.py (v1), models/early_fusion_v2/model.py (v2)

  Fusion:    Learnable 1x1 Conv2d projects the 4-channel fused RGBT input down
             to 3 channels (identity-initialised on RGB, zero on IR) before
             the backbone. Lets the network learn an optimal channel mix
             from the start of training while keeping pretrained backbone
             weights intact.

  Backbone:  MobileViT-S (v1) / MobileViTv2-100 (v2), same fallback behaviour
             as 5.1.

  Decoder:   v1 uses common.heads.MobileViTSegmentationHead (plain bilinear
             upsampling, same as 5.1). v2 uses models.early_fusion_v2.model.
             ASPPDecoder (atrous spatial pyramid pooling: parallel dilated
             convs at rates 1/6/12/18 + global average pooling, concatenated
             and projected, then 2 progressive upsample+refine steps) to
             recover fine structural detail lost in deep backbone features.

  Loss:      v1 uses weighted CrossEntropyLoss (same weights as 5.1). v2 uses
             models.early_fusion_v2.model.FocalDiceLoss — Focal (gamma=3,
             weight 0.6) + soft Dice over classes 1-4 (weight 0.4), with
             data-driven class weights (moisture boosted x5) computed by
             models.early_fusion_v2.train._compute_class_weights.

  Forward signature:
    model(fused: Tensor[B,4,H,W]) → logits: Tensor[B,num_classes,H,W]

5.3 CNNViTSelfSegmentationModel  (from-scratch CNN + self-attention hybrid)
------------------------------------------------------------------------------
File: models/CNN_VIT_SELF/model.py

  The only model in this repo not built on a timm pretrained backbone.
  Consumes the 4-channel fused RGBT input directly (no channel-projection
  layer, since there is no pretrained 3-channel stem to protect).

  Stem + stages 1-2: pure CNN (depthwise-separable "inverted residual"
                      blocks, models.CNN_VIT_SELF.model.CNNStage), each
                      halving spatial resolution.
  Stages 3-4:         models.CNN_VIT_SELF.model.CNNViTBlock — local
                      depthwise-separable conv (handles the 2x downsample)
                      + one pre-norm Transformer encoder layer (multi-head
                      self-attention + MLP) over the flattened feature map,
                      fused back via a 1x1 conv + residual. Attention is
                      only applied here, once the token grid is small enough
                      (H/16, H/32) to be cheap — same "local-then-global"
                      idea MobileViT is built on, reimplemented with plain
                      nn.MultiheadAttention.
  Positional encoding: 2D sinusoidal, computed fresh per forward pass from
                      the actual feature-map size (not a fixed-size learned
                      table).
  Decoder:            common.heads.MobileViTSegmentationHead (same shared
                      decoder as 5.1/5.2's v1 variants).
  Loss:               common.losses.FocalDiceLoss (same as 5.2's v2).

  Forward signature:
    model(fused: Tensor[B,4,H,W]) → logits: Tensor[B,num_classes,H,W]

5.4 MobileNetV4SegmentationModel  (early fusion, MobileNetV4 backbone)
--------------------------------------------------------------------------
File: models/mobilenet_v4/model.py

  Same early-fusion pattern as 5.2 (learnable 1x1 conv projects the
  4-channel fused RGBT input down to 3 channels so a pretrained 3-channel
  backbone can be reused unmodified), with a MobileNetV4-Conv-Medium
  backbone instead of MobileViT(v2). Backbone selection rationale — TIMM
  benchmark rankings across 222 mobile ImageNet models — is documented in
  docs/MobileRankings_TIMM.docx; mobilenetv4_conv_medium (~9.7M params,
  ~82-83% ImageNet Top-1) was chosen as the mid-size variant, falling back
  to mobilenetv4_conv_small if unavailable.

  Decoder: common.heads.MobileViTSegmentationHead (same as 5.1/5.2's v1
           variants).
  Loss:    common.losses.FocalDiceLoss (same as 5.2's v2 and 5.3).

  Forward signature:
    model(fused: Tensor[B,4,H,W]) → logits: Tensor[B,num_classes,H,W]

5.5 LateFusionSegmentationModel / LateFusionSegmentationModelV2  (dual-modal)
--------------------------------------------------------------------------------
Files: models/late_fusion_v1/model.py (v1), models/late_fusion_v2/model.py (v2)

  Backbone (RGB): MobileViT-S (v1) / MobileViTv2-100 (v2), 3-channel input,
                  pretrained weights.
  Backbone (IRT): Same architecture, 1-channel input.
                  Adaptation: first Conv2d weight summed across RGB channel dim,
                  preserving pretrained filter energy.

  Fusion:  Modality attention gates at decoder levels 1 & 2.
           Levels 3–5 use a single fused representation.

  Forward signature:
    model(rgb: Tensor[B,3,H,W], irt: Tensor[B,1,H,W]) → logits: Tensor[B,num_classes,H,W]

  Training pipeline (models/late_fusion_v1/train.py, models/late_fusion_v2/
  train.py) was added as part of the models/ reorganization — the original
  codebase shipped only the model definitions with a shape smoke-test.

5.6 ModalityAttention  (inside LateFusionSegmentationModel/V2)
------------------------------------------------------------------
Files: models/late_fusion_v1/model.py, models/late_fusion_v2/model.py

  Learns per-pixel importance weights for each modality at a given decoder level.
  Output: weighted combination of RGB and IRT features.
  Applied only at coarse resolutions (levels 1 & 2) where cross-modal context
  contributes most to segmentation accuracy.

6. TRAINING PIPELINE
================================================================================

Core trainer:  DefectDetectionTrainer, DefectDetectionMetrics  (common/trainer.py)
               Shared by every model below — none of them subclass or
               reimplement it, they just instantiate it.

Per-model pipeline classes (each is that model's train.py, with a
config.yaml-driven __main__ block):

  models/single_modal_v1/train.py  : DefectDetectionPipeline
  models/single_modal_v2/train.py  : DefectDetectionPipelineV2
  models/early_fusion_v1/train.py  : EarlyFusionPipeline
  models/early_fusion_v2/train.py  : EarlyFusionPipelineV2
  models/CNN_VIT_SELF/train.py     : CNNViTSelfPipeline (same training recipe
                                      as EarlyFusionPipelineV2 — see 5.3)
  models/mobilenet_v4/train.py     : MobileNetV4Pipeline (same training
                                      recipe as EarlyFusionPipelineV2 — see 5.4)
  models/late_fusion_v1/train.py   : LateFusionPipeline   (added during the
                                      models/ reorganization — see 5.5)
  models/late_fusion_v2/train.py   : LateFusionPipelineV2 (added during the
                                      models/ reorganization — see 5.5)

DefectDetectionTrainer auto-detects batch type:
  - Batch has key "image"       → single-modal forward path: model(image)
  - Batch has keys "rgb"/"irt"  → dual-modal forward path:   model(rgb, irt)
This allows the same trainer class to be shared by every pipeline above,
whether they're single-modal, early-fusion, or late-fusion.

6.1 Loss Function
-----------------
  torch.nn.CrossEntropyLoss(
      weight      = class_weights,   # [0.2, 3.0, 2.0, 1.0, 3.0]
      ignore_index = -1              # masks invalid/border pixels
  )

  Class weights:
    Background   (0): 0.2   ← heavily downweighted; dominates pixel count
    Crack        (1): 3.0   ← upweighted; thin, rare feature
    Spall        (2): 2.0
    Delamination (3): 1.0   ← neutral; no annotations yet
    Moisture     (4): 3.0   ← upweighted; irregular shape, rare

6.2 Optimizer & Scheduler
--------------------------
  Optimizer: Adam
    lr           = 0.001
    weight_decay = 0.0001

  Scheduler: ReduceLROnPlateau
    mode         = 'max'     (monitored metric: validation mean IoU)
    factor       = 0.5       (halve LR on plateau)
    patience     = 10 epochs

6.3 Gradient Clipping
----------------------
  torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
  Applied every training step before optimizer.step().

6.4 Checkpointing
-----------------
  Saved when validation score improves (mean IoU for most pipelines; early
  fusion v2 uses a partial mIoU that excludes moisture — see 5.2/6.5). Each
  model saves into its own models/<name>/checkpoints/ folder; only the top
  `keep_best_n` checkpoints by score are kept, older ones are pruned
  automatically (common.trainer.save_and_prune_checkpoint).
  Filename pattern (per model, in its own checkpoints/ folder):
    best_single_modal_epoch{epoch:03d}.pth      (models/single_modal_v1)
    best_single_modal_v2_epoch{epoch:03d}.pth   (models/single_modal_v2)
    best_early_fusion_epoch{epoch:03d}.pth      (models/early_fusion_v1)
    best_early_fusion_v2_epoch{epoch:03d}.pth   (models/early_fusion_v2)
    best_cnn_vit_self_epoch{epoch:03d}.pth      (models/CNN_VIT_SELF)
    best_mobilenet_v4_epoch{epoch:03d}.pth      (models/mobilenet_v4)
    best_late_fusion_epoch{epoch:03d}.pth       (models/late_fusion_v1)
    best_late_fusion_v2_epoch{epoch:03d}.pth    (models/late_fusion_v2)

  Checkpoint contents:
    {
      "epoch":           int,
      "model_state":     model.state_dict(),
      "optimizer_state": optimizer.state_dict(),
      "metrics":         dict,
      "best_metric":     float
    }

6.5 Early Stopping
------------------
  Monitored metric: validation mean IoU
  Patience:         20 epochs (early_stopping_patience in config)
  Behavior:         Training halts if no improvement for 20 consecutive epochs.


================================================================================
7. EVALUATION METRICS
================================================================================

Class: DefectDetectionMetrics  (common/trainer.py)

Implemented via confusion matrix accumulation (per-pixel predictions vs GT).

Metrics computed per epoch:
  - Accuracy (Overall):   sum(diagonal) / sum(confusion matrix)
  - Per-class IoU:        TP / (TP + FP + FN)
  - Mean IoU:             mean of per-class IoU  ← primary checkpoint metric
  - Per-class Dice:       2·TP / (sum(pred_class) + sum(gt_class))
  - Mean Dice:            mean of per-class Dice
  - Macro F1 (defects):   mean F1 over classes 1–4 only (background excluded)
                           F1 = 2·P·R / (P + R)

Output dict structure:
  {
    "loss":          float,
    "accuracy":      float,
    "mean_iou":      float,
    "mean_dice":     float,
    "macro_f1":      float,
    "iou_per_class": [float, float, float, float, float],
    "dice_per_class":[float, float, float, float, float]
  }

Note: Macro F1 excludes background to focus evaluation on defect classes.

================================================================================
10. NOTABLE DESIGN DECISIONS
================================================================================

1. LATE FUSION OVER EARLY FUSION
   RGB and IRT are processed by separate backbones and fused only at the decoder.
   This lets each modality develop independent high-level representations before
   being combined, which is beneficial when modalities carry complementary
   (not just redundant) information (e.g., RGB captures surface texture; IRT
   captures subsurface thermal anomalies).

2. MODALITY ATTENTION AT COARSE SCALES ONLY
   Modality attention gates are applied at decoder levels 1 & 2 (lowest
   resolution). At coarse scales, spatial context is wide enough for the model
   to learn where each modality is informative. Higher-resolution levels (3–5)
   use a single fused pathway to save memory and computation.

3. THERMAL CHANNEL ADAPTATION
   The IRT backbone's first Conv2d is converted from 3-channel to 1-channel by
   summing pretrained RGB filters. This preserves the energy/magnitude of the
   original pretrained filters, allowing the thermal backbone to leverage
   ImageNet pretraining despite the different input modality.

4. CRACK RENDERING AS POLYLINES
   Cracks are annotated as polylines in CVAT and rendered as thick lines
   (width = 10 px) rather than filled polygons. This matches the actual
   morphology of cracks (thin, elongated features) and avoids incorrect area
   masks that filled polygon rendering would produce.

5. SYNCHRONIZED MULTI-MODAL AUGMENTATION
   Using albumentations' `additional_targets` ensures that spatial transforms
   (flips, rotations, shifts) are applied identically to RGB image, IRT image,
   and segmentation mask. Applying transforms independently would cause
   pixel-level misalignment between modalities and labels.

6. ONE SHARED TRAINER FOR EVERY MODEL
   DefectDetectionTrainer (common/trainer.py) detects the batch type (single
   vs. multi-modal) via dict keys and dispatches to the appropriate forward
   path. This avoids code duplication and ensures all six pipelines
   (single-modal, early-fusion, late-fusion; v1 and v2) share the same
   training logic, metric computation, and checkpointing behavior — a fix
   to the trainer applies to every model at once.

7. BACKGROUND DOWNWEIGHTING
   Background pixels are assigned a class weight of 0.2. Without downweighting,
   the model would be incentivized to predict everything as background and
   still achieve high accuracy, ignoring rare defect classes.

8. IGNORE INDEX FOR INVALID PIXELS
   The loss function uses ignore_index=-1, allowing any pixel labeled -1 to be
   excluded from loss computation. This supports masking image borders, padding
   regions, or any area the annotator explicitly left unlabeled.

9. ANNOTATION AUTO-REGENERATION
   Every models/<name>/train.py's __main__ block checks whether the COCO JSON
   files exist and are non-empty. If not, it automatically triggers
   CVATXMLToCOCOConverter to (re)generate them. This makes each pipeline
   self-contained from raw CVAT annotations, independent of which model you
   train first.
