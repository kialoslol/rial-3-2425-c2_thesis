# Early Fusion v2 — MobileViTv2-100 + ASPP (primary model)

The most-trained and best-performing model in this repo. 4-channel RGB+IR
fused imagery through a MobileViTv2-100 backbone, an ASPP decoder for fine
structural detail recovery, and a Focal+Dice loss tuned for the severe class
imbalance in this dataset (background dominates; moisture is <0.1% of pixels).

## Architecture

| Component | Detail |
|---|---|
| Backbone | MobileViTv2-100 (`timm`, ImageNet-pretrained), falls back to `mobilevitv2_075` |
| Fusion strategy | Early Fusion — learnable 1x1 conv projects 4ch RGBT -> 3ch |
| Decoder | Atrous Spatial Pyramid Pooling (`ASPPDecoder`) — recovers crack-edge / moisture-boundary detail lost in deep backbone features |
| Loss | `FocalDiceLoss` — Focal (gamma=3, weight=0.6) + soft Dice over classes 1-4 (weight=0.4) |
| LR schedule | `CosineAnnealingWarmRestarts` (T_0 scales with `num_epochs`, T_mult=2) |
| Class weights | Data-driven inverse-frequency from annotation pixel counts, moisture boosted x5, background floor 0.5 |
| Sampling | Moisture-containing images oversampled x4 via `WeightedRandomSampler` |
| Early stopping | Tracks *partial* mIoU (background/crack/spall/delamination only) until moisture stabilises |
| Input | `[B, 4, H, W]` (fused RGB+IR TIFF) |
| Output | `[B, 5, H, W]` logits |

### Class Map

| ID | Class | Notes |
|---|---|---|
| 0 | Background | Dominant class; down-weighted by Focal Loss |
| 1 | Crack | Surface fractures |
| 2 | Spall | Concrete spalling |
| 3 | Delamination | Reserved (no annotations in current dataset) |
| 4 | Moisture | Moisture infiltration; inverse-frequency boosted x1.8-5x depending on run |

## Training Results (200-epoch run)

### Best Validation Metrics (Epoch 200)

| Metric | Value |
|---|---|
| Loss | 0.4110 |
| Pixel Accuracy | 71.89% |
| Mean IoU | 47.12% |
| Mean Dice | 58.95% |
| Macro F1 | 52.82% |
| mAP | 51.59% |

### Per-Class Breakdown

| Class | Accuracy | IoU | Dice | Precision | Recall | F1 |
|---|---|---|---|---|---|---|
| Background | 0.7295 | 0.7158 | 0.8344 | 0.9950 | 0.7184 | 0.8344 |
| Crack | 0.9858 | 0.4467 | 0.6175 | 0.5491 | 0.7054 | 0.6175 |
| Spall | 0.9901 | 0.5955 | 0.7465 | 0.7552 | 0.7379 | 0.7465 |
| Delamination | 0.9924 | 0.5978 | 0.7483 | 0.7588 | 0.7380 | 0.7483 |
| Moisture | 0.7401 | 0.0003 | 0.0006 | 0.0003 | 0.8696 | 0.0006 |

> **Note on Moisture:** near-zero IoU/F1 despite high recall (0.87) means the
> model predicts moisture almost everywhere — false positives dominate. The
> `predict()` method's confidence-thresholded fallback (see below) mitigates
> this at inference time; the underlying class imbalance is still open work.

## Files

- `model.py` — `EarlyFusionSegmentationModelV2`, `ASPPDecoder`, `FocalDiceLoss`
- `train.py` — `EarlyFusionPipelineV2` (train / predict / `inspect_ir_weights`) + config-driven `__main__`

## Usage

```bash
python models/early_fusion_v2/model.py   # shape smoke-test (no training)
python models/early_fusion_v2/train.py   # full training run, reads config.yaml
```

Checkpoints save to `models/early_fusion_v2/checkpoints/` as
`best_early_fusion_v2_epoch{N:03d}.pth`, along with `training_history.json`
for `common/visualization.py`:

```bash
python common/visualization.py models/early_fusion_v2/checkpoints/training_history.json
```

### Inference with moisture confidence thresholding

```python
from models.early_fusion_v2.train import EarlyFusionPipelineV2

pipeline = EarlyFusionPipelineV2(
    fused_dir="./ANNOTATED_DATA",
    annotation_dir="./dataset",
    num_classes=5,
)
result = pipeline.predict(
    fused_path="./ANNOTATED_DATA/fuse_Binondo/000001.tiff",
    checkpoint_path="./models/early_fusion_v2/checkpoints/best_early_fusion_v2_epoch199.pth",
)
# result["mask"] — H x W numpy array of class IDs (0-4)
# result["rgb"]  — H x W x 3 RGB image
```
